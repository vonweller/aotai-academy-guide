# 鳌台书院 · AI 非遗导览 —— 使用说明

> 一套「CyberCAM（K230）+ 行空板 K10 + PC 网页 3D」的非遗导览装置。
> 五关式动线：门口人脸识别 → 前院溯源 → 讲堂楹联 → 非遗工坊 → 尾声留墨。

---

## 1. 最快演示（只要一台电脑）

```bash
pip install flask paho-mqtt          # 只需一次
python 03_网页3D/bridge/run_demo.py  # 同时起 MQTT Broker(:1883) 与网页(:8000)
```

浏览器打开 `http://127.0.0.1:8000/`（投影端可用控制台打印的局域网地址）。
**不接任何硬件也能完整走完五关**——这是答辩保险方案。

快捷键：`N` 下一关 / `P` 上一关 / `空格` 重播 / `L` 切粤语 / `R` 重置 / `C` 换机位 / `1`–`5` 直达。

## 2. 接上 CyberCAM（K230）

1. CyberCAM 与电脑连同一 WiFi；电脑 IP 记作 `PC_IP`。
2. 改 `01_固件/CyberCAM_AI书院/config.py` 里的 `MQTT_HOST = "PC_IP"`。
3. 把整个 `CyberCAM_AI书院` 文件夹改名为 `aotai`，拷到板子 `/data/app/aotai/`（媒体盘直接拖）。
   再把 `02_数据` 整个拷贝成板子的 `/data/aotai/`（content.json + audio + faces）。
4. 板上执行（或用 VSCode CyberCAM 插件运行 `main.py`）：
   ```bash
   cd /data/app/aotai && python main.py
   ```
5. 桌面图标：拷贝完后执行 `echo root | sudo -S kill $(pgrep -x lvglsim)` 重启桌面。
6. 首次若触摸坐标不对：按 K 键也能推进；或在 `/data/aotai/touch_calib.json` 里写三点标定。

**现场注册人脸**：站在镜头前，按板载 K 键 → 当前人脸被注册为「预约访客」并写入 `/data/aotai/faces/`。
**打印用样张**：`02_数据/data_pack/faces/1_01.jpg`（A4 打印即可被识别）。

**没有摄像头/没网时**：`python main.py --demo` 走演示模式，按 S 模拟识别成功。

---

## 3. 接上行空板 K10

1. 改 `01_固件/K10_AI书院/secrets.h` 的 WiFi 名/密码与 `MQTT_HOST`（= PC_IP）。
2. 编译烧录（Windows，Git Bash）：
   ```bash
   K10_MODEL=Hi_eps bash ~/.agents/skills/arduino-esp32s3-k10-xiaosense/scripts/compile-k10.sh \
     "./01_固件/K10_AI书院" COM12
   ```
   （`COM12` 换成实际串口；必须带中文模型，否则 ASR 不工作）
3. 用前说唤醒词：**「你好小行」或「你好小新」**，然后说：
   - 下一关 / 上一关 / 重播
   - 普通话 / 粤语
   - 重新开始 / 人脸识别
4. K10 屏幕显示关卡、语言、WiFi/MQTT 状态、最近一条指令；A 键=下一关，B 键=切语言，A+B=重播。

## 4. 三端联动原理

```
CyberCAM ──aotai/event──▶  Flask(PC) ──SSE──▶  网页3D
   ▲                          │
   └────aotai/cmd─────────────┘
K10 ───aotai/k10 + aotai/cmd──▶ Flask ──▶ 网页 & CyberCAM
```

- `aotai/state`：保留状态（stage/lang/face_ok），新接入的端立即同步。
- `aotai/event`：CyberCAM 的人脸/关卡/播报事件。
- `aotai/cmd`：网页或 K10 发出的控制命令。
- 完整字段见 `06_文档/协议.md`。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 网页显示「本地演示」 | Flask 没起或端口被占：`python 03_网页3D/bridge/run_demo.py` |
| 网页显示「MQTT 离线」 | broker 没起：run_demo.py 会自带；若用 mosquitto 检查 1883 端口 |
| CyberCAM 无声音 | `aplay -l` 看声卡名，把 `config.AUDIO_CMD` 改成对应 plughw |
| 人脸永远 unknown | 人脸库为空：按 K 键现场注册，或检查 `/data/aotai/faces/` |
| K10 说完没反应 | 1) 确认烧录时带 `K10_MODEL=Hi_eps`；2) 确认 WiFi/MQTT 已连（屏幕第 4 行） |
| 网页很卡 | 换 Chrome/Edge；`C` 切机位减少可见面数；或把 GLB 换成低模版本 |
| 3D 场景加载不出来 | 确认 `assets/aotai_academy.glb` 存在（0.8 MB）；缺了会自动退回程序化场景 |

## 6. 素材再生成

- **语音**：改 `02_数据/content.json` → `python 02_数据/tools/gen_audio.py`（自动 edge-tts + ffmpeg）。
- **3D 场景**：`blender -b --factory-startup -P 05_Blender/lib/build_academy.py` → 拷 `out/*.glb` 到 `03_网页3D/assets/`。
- **PPT**：`python 04_PPT/build_ppt.py`（自动引用最新渲染图与网页截图）。
- **人脸样张**：`python 01_固件/CyberCAM_AI书院/tools/prepare_face.py --out 02_数据/data_pack`。
- **UI 自检图**：`python 01_固件/CyberCAM_AI书院/tools/selftest_ui.py` → `qc/*.png`。

### 语音引擎（双轨）
- **普通话**：阿里云 Qwen3-TTS（`qwen3-tts-flash`，音色 `Cherry`），28 条
- **粤语**：微软 edge-tts `zh-HK-HiuMaanNeural`（真粤语发音），28 条
  - 原因：千问 TTS 当前 `language_type` 只支持 chinese/english/german/italian/portuguese/spanish/japanese/korean/french/russian/auto，**没有粤语**；用 chinese 读粤语字会读成普通话。
- 生成脚本：`python 02_数据/tools/gen_audio.py --lang zh --engine qwen --force`
- 密钥放在 `02_数据/tools/.dashscope_key`（gitignore 掉，不要外传）

### CyberCAM 卡死原因与修复
**原因**：APP 与桌面 `lvglsim` 抢 `/dev/fb0`，我先 `kill lvglsim` 再启动 APP，内核 fb/DRM 进入 D 状态，导致整机 IO 卡死（SSH 端口还在但不再响应，ping 也不通）。

**修复**（已写进 `01_固件/CyberCAM_AI书院/display.py`）：
1. 启动时探测桌面，**用官方 desktop 脚本反向操作**温和停掉，而不是直接 kill；
2. Display 初始化加超时与 try/except，失败就只用 IDE 通道，**绝不卡主循环**；
3. 所有 `Display.show` 包异常保护，失败一次就永久降级；
4. 退出时自动 `sudo desktop` 恢复桌面。
5. 新增 `--no-display` 参数：远程调试时完全不占屏。

**恢复步骤**：CyberCAM 断电 → 重新上电 → 等 30 秒 → 运行
```bash
python _cam_recover.py --deploy --start
```

### 现场演示顺序
1. `python 03_网页3D/bridge/run_demo.py`（或双击「一键演示.bat」）
2. 浏览器打开 http://127.0.0.1:8000/ ，状态条出现「K10 在线」
3. CyberCAM 上电，跑 `_cam_recover.py --deploy --start`
4. 对 K10 说 **「你好小行」** → 说 **「下一关」** → 网页小人开始走
**注意**：K10 固件已**关闭本地 TTS**（ASR 库的 TTS 队列在部分固件上会 assert 崩溃），播报统一由 CyberCAM 负责。
