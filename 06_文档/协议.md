# 鳌台书院 AI 非遗导览系统 · 总体设计与接口协议 v1

> 唯一真源。所有模块（CyberCAM / K10 / 网页3D / PPT / Blender）只读本文件的约定，不自造字段。

## 0. 项目定位
东莞厚街·鳌台书院（岭南书院）AI 非遗导览装置：
- **CyberCAM（K230）**：人脸检测/识别、五关交互 UI、双语 TTS 播报、MQTT 上报。
- **行空板 K10**：语音唤醒（你好小行）、关键词识别（下一关/上一关/重播/粤语/普通话）、K10 屏幕状态、RGB、MQTT 触发。
- **PC 网页 3D**：Blender 建模的鳌台书院三维场景 + 小人（书生）在地图行走 + 五关交互 + 语音播报 + 大屏展示（投影/电视）。
- **PPT**：评委讲解用，可本地播放。

## 1. 五关动线（固定）
| 关 | 名称 | 场景位置 | 触发 | 交互 | 完成条件 |
|---|---|---|---|---|---|
| 1 | 门口迎宾·人脸识别 | 书院大门/牌匾前 | 人脸检测到 | 人脸识别→播报欢迎语（按语言） | 识别成功（或3秒未注册进入访客模式） |
| 2 | 前院·鳌台溯源 | 前院天井/假山 | 上一关完成 | 书院历史介绍 + AI 问答1题（三选一） | 答对/答错都有反馈，播报评语 |
| 3 | 讲堂·楹联诵读 | 讲堂（主体建筑内） | 上一关完成 | 展示楹联/匾额，语音领读一句 | K10 关键词"下一关"或屏幕点击 |
| 4 | 庭院·非遗工坊 | 侧院/云墙漏窗前 | 上一关完成 | 岭南非遗小知识（如莞草编织/香云纱），选择题 | 答完 |
| 5 | 尾声·留墨寄愿 | 出口/文昌位 | 上一关完成 | 结语 + 主题曲 + 建议参观路线 | 结束并可重置 |

> 实物模型侧：每关完成后由人工把小人摆到下一关位置；网页端同步点"下一关"，3D 小人沿路径走过去。

## 2. 语言
- 两种：`zh`（普通话）/ `yue`（粤语，TTS 用 zh-HK 音色近似演绎）。
- 选择入口：① CyberCAM 首屏触摸/按键选择；② K10 唤醒词后说"普通话/粤语"；③ 网页按钮。
- 播报文本全部来自 `02_数据/content.json`（zh/yue 双语），音频缓存 `02_数据/audio/{zh|yue}/{id}.mp3` + `manifest.json`。
- **本地优先**：板端先查 audio 目录，有就播放，没有就按 API 在线合成后存本地。

## 3. 硬件与网络
- CyberCAM：WiFi，账号 pi/pi（root/root）；APP 放 `/data/app/aotai/"。
- K10：WiFi + MQTT。唤醒词"你好小行/你好小新"，指令用拼音。
- PC：跑 **MQTT broker（默认本机 1883）** + **网页3D（静态+HTTP）** + **WebSocket 桥**。
- 局域网地址约定：PC = `192.168.1.100`、CyberCAM = `192.168.1.101`、K10 = `192.168.1.102`（现场按实际改，配置集中在一个文件）。

## 4. MQTT 主题与消息（JSON，UTF-8）
Broker 端口 1883，无鉴权（内网演示）。客户端 ID：`cybercam-01` / `k10-01` / `pc-bridge`。

### 4.1 `aotai/state`（retained，所有方都订阅）
当前全局状态，任意方广播后更新：
```json
{"stage":1,"lang":"zh","visitor":"预约访客","face_ok":true,"updated":"2026-10-20T15:00:00+08:00"}
```

### 4.2 `aotai/event`（事件流：CyberCAM/K10 → PC桥 → 网页）
```json
{"type":"face_detected","stage":1,"lang":"zh"}
{"type":"face_recognized","stage":1,"visitor":"预约访客","lang":"zh"}
{"type":"face_unknown","stage":1}
{"type":"lang_changed","lang":"yue"}
{"type":"stage_enter","stage":2}
{"type":"stage_done","stage":2,"ok":true}
{"type":"quiz_answered","stage":2,"qid":"q1","answer":"B","ok":true}
{"type":"speak","id":"welcome_zh","text":"……","lang":"zh"}
{"type":"reset"}
```

### 4.3 `aotai/cmd`（控制：PC网页/K10 → CyberCAM）
```json
{"cmd":"set_lang","lang":"zh|yue"}
{"cmd":"goto_stage","stage":2}
{"cmd":"next"}  {"cmd":"prev"}  {"cmd":"repeat"}
{"cmd":"quiz","stage":2,"qid":"q1"}
{"cmd":"speak","id":"stage2_intro","lang":"yue"}
{"cmd":"reset"}
```

### 4.4 `aotai/k10`（K10 → 全网：唤醒与关键词）
```json
{"type":"wake","score":0.9}
{"type":"voice_cmd","cmd":"next","text":"下一关"}
{"type":"voice_cmd","cmd":"lang_yue","text":"粤语"}
{"type":"k10_status","lang":"zh","stage":2}
```

### 4.5 `aotai/web`（网页 → 全网：看板操作）
```json
{"action":"goto","stage":3,"lang":"zh","source":"web"}
{"action":"speak","id":"stage3_line1","lang":"zh"}
{"action":"reset"}
```

## 8. 验收标准（每模块自检并写 README 自检记录）
1. **cybercam**：板上能跑，首屏语言选择→人脸→五关可走完；无 MQTT 也能本地演示（离线降级）。
2. **k10**：唤醒后说"下一关"能发 MQTT；屏幕显示当前关卡与语言；打字"下一关"也能触发。
3. **web3d**：打开 index.html 即可演示，键盘/按钮/鼠标都能推进；小人沿路径平滑行走；语音随语言切换。
4. **blender**：输出 `aotai_academy.glb`（≤ 15MB，5 关场景齐全），并有 4 张固定机位渲染图供 PPT 用。
5. **ppt**：12–16 页，含封面、痛点、方案、架构图、五关流程、演示截图、创新点、展望。
